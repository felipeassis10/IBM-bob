# 🌍 Geo-Explorer

> **A professional MCP server + interactive CLI for developer learning tracks, ASCII-art certificates, and AI-driven certificate verification.**

Geo-Explorer is a Node.js/TypeScript project that implements a [Model Context Protocol (MCP)](https://modelcontextprotocol.io) server. It exposes four tools — `get_track`, `get_challenge`, `generate_certificate`, and `verify_certificate` — so that any AI agent (Claude, IBM Granite, etc.) can query a curated catalogue of developer learning paths, issue verifiable certificates, and verify them programmatically. It also ships a full **interactive terminal CLI** built with `chalk` and `inquirer`.

## Running the MCP Server

### Development mode (ts-node, no build step)

```bash
npm run dev
```

### Production mode (compile first, then run)

```bash
npm run build
npm start
```

The server communicates over **stdio** following the MCP specification. To connect it to an AI client, point the client's MCP configuration to this process. Example entry for a Claude Desktop `mcp_servers.json`:

```json
{
  "geo-explorer": {
    "command": "node",
    "args": ["/absolute/path/to/geo-explorer/dist/mcp/server.js"]
  }
}
```

## Available MCP Tools

| Tool | Description | Parameters |
|---|---|---|
| `get_track` | Returns the list of modules for a learning track | `tech` (string) |
| `get_challenge` | Returns a coding challenge for a technology + level | `tech` (string), `level` (`iniciante` \| `intermediario`) |
| `generate_certificate` | Generates a certificate of completion with a unique code | `userName` (string), `tech` (string) |
| `verify_certificate` | Verifies a certificate code and returns its details | `code` (string, e.g. `GEO-A8F9`) |

### Supported tracks

| id | Name |
|---|---|
| `nodejs` | Node.js |
| `python` | Python |
| `typescript` | TypeScript |
| `rpa-python` | RPA com Python e SQL |

### Example agent invocation

```
User → AI agent:
"Get me the Node.js beginner challenge."

AI agent → MCP tool call:
get_challenge({ tech: "nodejs", level: "iniciante" })

MCP server response:
{
  "tech": "nodejs",
  "level": "iniciante",
  "challenge": {
    "title": "Hello, World! API",
    "description": "Build a simple HTTP server..."
  }
}
```

## Running the Tests

The project uses [Jest](https://jestjs.io/) with `ts-jest` for TypeScript-native unit testing.

```bash
npm test
```

To run tests with a detailed coverage report:

```bash
npm test -- --coverage
```

The test suite covers:

- `getTrack()` — valid track, case-insensitivity, unknown technology error, **RPA track modules**
- `getChallenge()` — correct challenge content, invalid level, unknown technology, **RPA challenges**
- `generateCertificate()` — user name formatting, track name, module count, unique code format, store persistence, **RPA certificate**
- `verifyCertificate()` — successful lookup, case-insensitive code, invalid code error, **RPA verification**, store-cleared scenario

## Interactive CLI

The project ships a fully interactive terminal experience powered by **chalk** (colours) and **inquirer** (prompts).

```bash
npm run cli
```

The CLI presents a main menu with four options:

| Option | What it does |
|---|---|
| 📚 View learning track modules | Lists all modules for a chosen track with numbered, coloured output |
| ⚡ Get a coding challenge | Prompts for track + level, displays the challenge in formatted text |
| 🎓 Generate a certificate | Prompts for name + track, renders the ASCII-art certificate with syntax highlighting |
| 🔐 Verify a certificate code | Looks up a `GEO-XXXX` code and shows full record or a clear error |

## ✨ Diferenciais do Projeto

### 🤖 Trilha de RPA com Python e SQL (`rpa-python`)

A trilha de **Automação de Processos com Python e SQL** cobre habilidades práticas de alto valor no mercado: Web Scraping com BeautifulSoup e Selenium, transformação de dados com Pandas, integração com SQLite e PostgreSQL, e consumo de APIs REST com autenticação OAuth2. Inclui dois desafios práticos:

- **Iniciante** — Raspador de Notícias: extrai títulos e links de uma página HTML e salva em CSV.
- **Intermediário** — Pipeline de Dados com API + SQL: consome uma API REST, transforma com Pandas e persiste em SQLite com logs.

Os certificados são renderizados com molduras de terminal usando caracteres Unicode box-drawing (`┌ ┐ └ ┘ │ ─ ├ ┤`). O conteúdo é centralizado automaticamente dentro da moldura e exibido com highlight colorido via `chalk` no CLI:

### 🔐 Sistema de Validação de Certificados por Código

`generateCertificate()` retorna `{ text, code }`. O `code` é um ID único no formato `GEO-XXXX`, gerado com caracteres alfanuméricos aleatórios e garantido único na sessão. Cada certificado é registrado num store em memória.

A função `verifyCertificate(code)` permite que qualquer agente de IA confirme a autenticidade de um certificado e recupere seus dados completos:

```json
{
  "code": "GEO-A8F9",
  "userName": "Fernanda Lima",
  "tech": "rpa-python",
  "trackName": "RPA com Python e SQL",
  "issuedAt": "June 15, 2025"
}
```

### 🌐 Servidor MCP com 4 Tools

O servidor MCP expõe **4 tools** que qualquer agente compatível pode invocar sem configuração adicional:

| Tool | Propósito |

| `verify_certificate` | Valida um código e retorna o registro completo |

O `src/cli.ts` usa **chalk** para highlight de texto e **inquirer** para navegação por menus, tornando a experiência completamente interativa no terminal sem necessidade de interface gráfica.

## Project Learnings

This project was built as a hands-on exercise to explore the following concepts:

### 1. Model Context Protocol (MCP)
MCP is an open protocol that standardises how AI models connect to external tools and data sources. By wrapping our business logic inside MCP `tool` definitions, any compatible AI agent can discover and invoke the server's capabilities without bespoke integration code.

### 2. TypeScript strict mode
Using `"strict": true` in `tsconfig.json` forces explicit typing at every boundary. This caught several potential runtime errors at compile time, particularly around JSON imports and optional object properties.

### 3. StdioServerTransport
The MCP SDK's `StdioServerTransport` lets the server communicate over standard input/output pipes — making it easy to spawn the process from any host without network configuration.

### 4. Test-driven thinking
Writing unit tests before or alongside the implementation helped define the expected contracts of each function. Jest's `toThrow` matcher was especially useful for verifying that error paths produce meaningful messages.

### 5. Separation of concerns
Keeping the data (`/src/data`), business logic (`/src/commands`), transport layer (`/src/mcp`), and the CLI (`/src/cli.ts`) in separate files made the codebase easy to navigate and test each layer in isolation.

### 6. Interactive CLI with chalk + inquirer
Using `chalk` v4 (CommonJS-compatible) and `inquirer` v8 provides a fully interactive terminal experience. The CLI is a standalone entry point that re-uses the same `commands/index.ts` functions, demonstrating how a single business-logic module can power multiple consumers (MCP server, CLI, tests) without duplication.
